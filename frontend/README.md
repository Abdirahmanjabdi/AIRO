# Sentinel Zero Frontend

This Vite application is the Sentinel Zero control surface.

## Local Development

```sh
npm install
npm run dev
```

The local dashboard runs on `http://localhost:8080`.

## Required Environment Variable

```sh
VITE_BRAIN_API_URL=http://localhost:8000
```

## Production Build

```sh
npm run build
```

Static assets are emitted to `dist/`.
